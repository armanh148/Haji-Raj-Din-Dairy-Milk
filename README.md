# Haji Raj Din Dairy Milk (Sahiwal) 🥛

> **حاجی راج دین ڈیری ملک، ساہیوال**  
> Pure Milk, Fresh Dahi, Pure Desi Ghee Halwajat, Khoya Kheer & Dairy Ice Cream

Multi-Branch Website & Desktop Expiry/Stock POS pitch web application built with **React.js**, **Vite**, and **Tailwind CSS**.

---

## 🌟 Key Highlights & Features

- **3 Active Branches in Sahiwal (57000):**
  - **Madhali Road Outlet** *(New 3rd Branch!)*
  - **Ghori Street Branch** *(Main City Hub)*
  - **Gujar Ahata Branch** *(Heritage Location)*
- **Interactive WhatsApp Order Assistant & Cart:** Pre-fills formatted orders directly to `+92 300 2743860`.
- **Celebrity Spotlight & Video:** Ramzan Jani farm visit video endorsement with verified customer feedback.
- **Auto-Loop Customer Reviews Carousel:** Verified local customer feedback auto-looping with pause-on-hover and responsive cards.
- **Multi-Branch & Expiry POS Pitch:** Interactive desktop POS terminal simulator with 4-hour milk expiry alert monitor and thermal receipt preview.
- **Full-Width & Fully Responsive Layout:** Beautifully responsive across mobile (2 cards per row), tablet, laptop, and desktop.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/armanh148/Haji-Raj-Din-Dairy-Milk.git

# Navigate to project folder
cd Haji-Raj-Din-Dairy-Milk

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
